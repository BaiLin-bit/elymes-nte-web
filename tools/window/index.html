三种聊天窗
旧 QQ 风就是现在这个窗口：File 页聊天，Enter 发送、Shift+Enter 换行。File 页没有发送键，直接回车即可。
千禧风Help →「千禧风窗口」→ 打开。独立 Edge 窗口，关掉它不影响这里的对话。
2D 界面Help →「2D 聊天界面」→ 打开。素材原图当背景，聊天框是重绘的 Win98 小窗（300×340），走透明浮层。
开窗限制旧 QQ 风与千禧风共用同一个 Edge 配置目录，同一时间只能开一个；2D 界面和桌宠共用同一条透明浮层，也只能加载一个——开 2D 会顶掉桌宠，想换回桌宠就先收起 2D 再打开桌宠。

桌宠
互动单击唤起聊天窗口；双击受击闪白；右键菜单：打开聊天 / 别躲我 / 随便逛逛 / 藏起来。
设置Edit 里调：角色大小、躲避距离、飞行速度、鼠标逗留、逗留半径、安静时间、活动范围内外环；改完按「保存」，桌宠立即生效，不用重启。
小提示打开「鼠标逗留」后，躲避距离与安静时间会置灰不生效；「安静时间」是让它隔一阵停下来歇一歇。
窗口操作
移动拖标题栏；标题栏按钮 ─ 最小化 / □ 最大化 / ✕ 关闭。
缩放拖四边或四角，八方向都能拉；最小 520×380，内容整张等比缩放。
2D 右键九宫格贴边定位、大小 小/中/大、聊天记录、收起窗口。
快捷键
Ctrl+Alt+Y开/关桌宠（装了「启动桌宠热键.vbs」才有；重启电脑后要再双击一次）。
常见问题
窗口打不开多半是 18800 端口被占，或上次 Edge 还挂着同配置目录；关掉旧窗重开，必要时重启 Coopanion。
点了没反应页面还是改之前的缓存；关掉窗口重新打开（或 Ctrl+R）即可。
设置没效果Edit 里改完要按「保存」，只改按钮不保存不会生效。
桌宠不见了可能被 2D 聊天界面顶掉了——两者只能加载一个；收起 2D 再打开桌宠。
窗口被压住用 Alt+Tab 切回来，或先关掉盖住它的全屏窗口。
维护小知识
改了页面tools\window 下的 html/css/js 改完，窗口 Ctrl+R 即生效。
改了代码src\index.mjs、tools\window-server.mjs、dist\webui.js 改完要重启 Coopanion。
升级插件升级会覆盖 tools 下的改动；重要补丁先备份（*.bak_日期），升级后重新应用。
